Mobile App AI-Powered 2024 – Present

MOBILINGO

A Duolingo-style English learning mobile app built specifically for Mobilis Algeria staff. Featuring gamified lessons, progress tracking, and interactive quizzes — entirely designed and developed from a personal idea into a fully working Expo app.

How It Was Built
1
Concept & Research
Identified the gap: Mobilis Algeria staff needed accessible English training. Researched Duolingo's pedagogy and gamification patterns to shape the app concept.
2
UX Design & Structure
Mapped out lesson flows, screen architecture, and user progression system. Designed a clean, mobile-first UI that keeps learners engaged.
3
React Web App (V1)
Built the first version as a React web application — interactive lessons, quizzes, and tracking fully functional in the browser.
4
React Native Conversion (V2)
Converted the web app to React Native using Expo — enabling testing on real physical Android/iOS devices and a native app experience.
5
Testing & Iteration
Deployed via Expo Go for device testing, iterated on navigation, animations, and content delivery based on real usage feedback.

1
Market Identification

3
Full Site Development
Built each site with hero sections, menus, gallery, about section, opening hours, location map, and contact/reservation CTAs. Mobile-responsive on all devices.
4
Pitch Preparation
Packaged demos as a professional portfolio pitch — showing restaurant owners exactly what their site would look like before paying. A trust-building sales strategy.
